# OpenList 分支（0.4.20）

在设置中配置唯一一个 OpenList 连接（填写地址和账号密码），测试保存后添加文件夹作为分类。首页和分类只读取一级作品目录，详情才读取作品和分季。资料固定 movie.nfo 与 poster.jpg；NFO 无缓存时获取一次，只有详情手动更新才重新下载。可见海报缺失自动下载，详情和列表共用缓存。分类刷新只更新一级列表和海报。保留进度、分季、自然集序和音轨，历史最多 12 部。

参考 my-tv 的 OkHttp API 网络层及 Media3 播放方式，使用 Media3 1.2.1 和 FFmpeg 音频扩展。使用 /api/auth/login、/api/fs/list、/api/fs/get 与 fs/get 返回的 raw_url 下载，移除 Ghosten 运行依赖。Token 仅驻留内存，401 重新登录一次，资料和视频下载不发送登录密码或 API token。

服务部署在子路径时填写包含子路径的首页地址。覆盖安装保留现有配置、缓存和观看记录。

构建仍仅在天翼云 server_id=19 /srv/davplayer，使用现有签名和 Docker 脚本。尚需用户手动验证真实播放。

播放仅使用 ExoPlayer + FFmpeg 音频扩展，不提供核心选择。播放进度、选集、音轨偏好继续保存；已有 ExoPlayer 音轨偏好直接复用。

构建、验证和当前验收边界见 [docs/verification.md](docs/verification.md)，播放生命周期见 [docs/playback.md](docs/playback.md)，资料规则见 [docs/cache.md](docs/cache.md)。FFmpeg 源码与重建说明见 [docs/media3-ffmpeg.md](docs/media3-ffmpeg.md)。

项目只提交当前应用源码、测试、构建脚本、图标源文件、NFO 示例及许可声明；签名、APK、缓存、源码快照和本地诊断材料由 .gitignore 排除。

横屏页面与弹窗采用沉浸式全屏，详情海报和剧集卡片使用紧凑横屏布局。

浏览目录与海报/NFO 共用串行队列，同一页面加载内的相同目录请求合并。首页/分类在配置与记录未变化的 30 秒内返回复用已显示列表；不增加持久目录缓存。详情到播放复用两分钟内、同账号且包含当前剧集的一次性选集快照；恢复入口缺少快照时先读选集，再排空队列并开始视频。

自动海报保持内存/磁盘缓存优先，可见稳定 180ms 后读取缺失资料，离屏 250ms 后取消，无人订阅才取消合并请求。缺失/失败冷却 30 秒；429/503 根据 Retry-After 秒数（至少 30 秒、最多一天）暂停自动海报；不轮询重试，手动刷新绕过自动冷却。分类手动刷新复用本次作品列表。

API 和资料下载共用无默认认证的 OkHttp 连接池，移除强制 Connection: close；认证仅在 API 请求添加。取消和超时继续关闭实际请求，视频传输保持现有实现。不记录地址、签名或账号。

唯一构建：minSdk18 / Media3 1.2.1 + FFmpeg，仅支持 arm64-v8a / armeabi-v7a。

```sh
./build-android-docker.sh testDebugUnitTest lintPreview assemblePreview
./verify-apk-docker.sh app/build/outputs/apk/preview/app-preview.apk
```

0.4.14：横屏详情左侧完整海报、右侧片名/资料/三行简介与播放/展开，下方选集；包含宽屏横屏资源适配，竖屏布局保持现状；声道切换移到进度条右侧，多音轨时显示。

详情支持导演、演员及角色、原名、首映、制作公司等 NFO 字段；空字段整项隐藏，宽横屏两列、竖屏单列。本版按要求重置海报/NFO 资料缓存，配置、分类、观看记录保留。

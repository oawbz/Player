# 列表、海报与 NFO

首页和分类页只读取一级作品目录；只有详情读取作品内容和分季。目录列表不持久缓存。过滤点号开头的文件和目录；作品按修改时间倒序、创建时间备用、未知时间最后，名称和路径稳定兜底；分季和剧集按文件名自然升序。

首页与分类页只为屏幕内可见卡片获取 poster.jpg。优先使用内存/磁盘缓存，缺图才下载，滚出屏幕取消未完成任务；已有完整缓存不自动联网校验。图片使用 12 MiB 位图 LRU，磁盘资料位于 files/openlist-resources-v1，不做自动容量淘汰；设置可统计缓存容量，用户确认后手动清理海报与简介缓存（不涉及配置、分类、历史或服务器文件）。网络失败不会清空已有有效缓存。

资料只使用固定 movie.nfo 和 poster.jpg。详情先显示本地海报及 movie.nfo 缓存，再开始目录读取；目录失败仍保留缓存展示。本页从播放器或后台返回复用目录，手动刷新重新读取目录与资料。详情先读 movie.nfo 缓存，无缓存才首次获取；已有缓存即复用，包括空简介和不存在结果。只有详情手动更新才重新下载 NFO；海报缺失仍自动补图。分类手动刷新只重读一级列表并串行刷新海报，不扫描作品目录、不获取 NFO。首页不提供刷新按钮。

NFO 最大 512 KiB，严格验证 UTF-8/XML；图片最大 8 MiB并在后台采样解码。资料 HTTP 有大小、超时和跳转上限，不向下载地址发送 OpenList 登录密码或 API token，不访问 NFO 内的外部图片或预告链接。

缓存文件名使用连接指纹和源路径散列，不含明文凭据。下载验证通过后原子替换，写入失败不当作缓存成功。文件格式维持当前版本，更新不会主动清除现有海报、配置或观看记录。自动/手动资料任务共享 ResourceGate，播放前取消并排空。

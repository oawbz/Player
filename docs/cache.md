# 列表、海报与 NFO

首页每次进入自动读取 OpenList 目录，分类页进入时获取当前分类；目录列表不持久缓存。过滤点号开头的文件和目录；作品按修改时间倒序、创建时间备用、未知时间最后，名称和路径稳定兜底；分季和剧集按文件名自然升序。

首页与分类页只为屏幕内可见卡片获取 poster.jpg。优先使用内存/磁盘缓存，缺图才下载，滚出屏幕取消未完成任务；已有完整缓存不自动联网校验。图片使用 12 MiB 位图 LRU，磁盘资料位于 files/openlist-resources-v1，不做自动容量淘汰。网络失败不会清空已有有效缓存。

进入详情只补缺失海报或空简介；优先 movie.nfo，再尝试 tvshow.nfo/同名 NFO。资料缺失可以在下次进入时重试。详情手动刷新无条件重新获取当前作品资料；分类手动刷新串行更新该分类作品。首页不提供刷新按钮。

NFO 最大 512 KiB，严格验证 UTF-8/XML；图片最大 8 MiB并在后台采样解码。资料 HTTP 有大小、超时和跳转上限，不向下载地址发送 OpenList 登录密码或 API token，不访问 NFO 内的外部图片或预告链接。

缓存文件名使用连接指纹和源路径散列，不含明文凭据。下载验证通过后原子替换，写入失败不当作缓存成功。文件格式维持当前版本，更新不会主动清除现有海报、配置或观看记录。自动/手动资料任务共享 ResourceGate，播放前取消并排空。

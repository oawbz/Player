# 播放与生命周期

设置与播放页可选择 MediaPlayer / ExoPlayer，默认 ExoPlayer。选择保存于应用私有配置，错误不会自动换核心。ExoPlayer 使用 Media3 1.8.0 官方 HTTP 数据源与 FFmpeg 音频扩展；MediaPlayer 使用系统网络和解码实现。视频不经过应用资料缓存，也不使用自定义视频 DataSource。

两个核心共用 PlaybackPlayer 接口与 OpenList fs/get 取址。播放页切核先保存进度与播放意图、释放旧实例，再重建所选核心。加载、切核和恢复时统一提示“缓冲中”。音轨偏好按核心隔离；现有 ExoPlayer 偏好仍可直接复用。MediaPlayer 不显示无法测量的下载速率。

打开媒体采用独立代次隔离迟到取址结果和播放器回调。退出、进入后台或 Surface 销毁时取消取址、释放实例并保存进度；返回后从保存位置恢复。MediaPlayer 恢复非零进度时等待异步跳转完成，暂停状态不会因此自动播放。

点击播放前，ResourceGate 暂停资料队列、取消当前资料请求并等待任务真实退出。分类手动刷新串行运行于同一队列，不创建额外批量线程池。选集目录读取只获取目录，不触发资料下载。

自动测试覆盖地址解析、取消、缓冲与音轨辅助逻辑，以及 MediaPlayer 准备/跳转/释放后的回调隔离。系统核心测试使用受控媒体回调，不替代手机上的实际解码、连续切核、前后台或遥控器验收。
